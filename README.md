# Lango — Android app

Download the latest app: **[Releases → latest → lango.apk](https://github.com/hjskhan/lango-releases/releases/latest/download/lango.apk)**

1. Open the link above on your Android phone (Android 8 or newer) and download `lango.apk`.
2. Open the downloaded file. Android asks to allow installing apps from your browser — allow it once.
3. Open Lango. Later updates are offered inside the app ("Update available" → Update).

This repository only holds the app file. It contains no book content.
