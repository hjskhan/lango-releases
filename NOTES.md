No more access code

Lango now works the moment you install it.

- When you first open the app it asks which languages you want to learn.
  Chapter 1 downloads straight away — no code to type, no account.
- The next chapter arrives by itself as you near the end of the one
  you are on, so it is ready when you get there.
- New app icon.

Already using Lango? Nothing to do. Your progress and your chapters stay
as they are, and the access code is simply no longer asked for.
